# Семантический поиск для библиографии исторического танца
(Проект по инфопоиску)

## CLI
Документация для CLI расположена в [infopoisk_docs.md](infopoisk_docs.md).

Там же указаны использованные модели и всё-всё-всё.

## Web interface
[www/main.py](www/main.py) запускает сайт библиографии, в который добавлен семантический поиск на FastText.

Так как корпус мультиязычный, использовались модели для каждого отдельного языка [отсюда](https://fasttext.cc/docs/en/crawl-vectors.html).
